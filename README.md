# behavior-analysis-ML
Projet universitaire réalisé en MIASHS visant à construire une pipeline d’analyse de données sous Orange Data Mining, combinant apprentissage supervisé et non supervisé.

Objectifs :
- Identifier des groupes d’avis cosmétiques similaires par clustering hiérarchique.
- Prédire la préférence télétravail / bureau à partir de variables socio-professionnelles.
- Comparer plusieurs modèles de classification et interpréter les résultats.

Technologies :
- Text Mining / NLP
- Classification
- Clustering
- Visualisation de données

Résultats principaux :
- Random Forest : meilleur modèle avec une précision d’environ 90 %.

- Le clustering met en évidence deux profils : sensorialité / douceur vs efficacité / résultats.

- Les variables les plus liées à la préférence pour le télétravail sont la productivité perçue, le sommeil, les économies réalisées et l’équilibre vie pro / perso.
